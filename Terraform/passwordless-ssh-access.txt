Change the file and folder permission of the public key and where it resides.

chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_rsa


cat .ssh/id_rsa.pub|ssh -i .ssh/id_rsa ubuntu@<Public_Ip> \
"cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"


If WSL is been used
Create a secure folder in your Linux home:
mkdir -p ~/.ssh

Copy the keys from Windows to Linux:

cp /mnt/c/Users/POPOOLA\ FAVOUR/Documents/Personal/Week11/Ansible/Terraform/.ssh/id_rsa ~/.ssh/
cp /mnt/c/Users/POPOOLA\ FAVOUR/Documents/Personal/Week11/Ansible/Terraform/.ssh/id_rsa.pub ~/.ssh/

Then restart the regular process.
